# BarberFlow

BarberFlow é um aplicativo móvel desenvolvido para auxiliar barbeiros no controle de atendimentos, faturamento e metas diárias e mensais.
O objetivo é substituir planilhas manuais por uma solução simples, segura e escalável, com interface intuitiva e recursos de gestão financeira.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
